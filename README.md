# Концепция нового сайта kuhni-remiz.ru

Отдельный статический шаблон для нового домена. Текущий сайт и три ранних концепта не изменялись.

## Визуальное направление

- спокойный архитектурный минимализм вместо типового «мебельного» лендинга;
- крупная редакционная типографика и много воздуха;
- тёплая натуральная палитра: молочный, графит, шалфей, древесный;
- продуктовая фотография занимает главную роль;
- короткий путь к заявке без агрессивных попапов и квизов;
- адаптивная версия для телефона и планшета.

## Временные элементы

Подключено 25 проектов и 70 оптимизированных визуализаций из архивов заказчика. Временные названия и описания находятся в `projects-data.js`: их можно заменить без изменения галерей и ссылок. Форма пока демонстрационная и не отправляет данные.

## Портфолио

- `portfolio.html` — каталог с фильтрами по категориям;
- `project.html?id=kitchen-01` — универсальная страница отдельной работы;
- `projects-data.js` — названия, категории, порядок, обложки и галереи;
- `assets/portfolio/` — подготовленные WebP-файлы и технический манифест.

## Запуск

Открыть `index.html` напрямую или перейти на `http://127.0.0.1:8080/kuhni-remiz/` при запущенном локальном сервере.
